OBJETIVO

Agregar un sistema profesional de tallas para los productos.

Debe ser completamente intuitivo tanto para el administrador como para el cliente.

El sistema debe ser escalable para que en el futuro puedan agregarse otros tipos de variantes sin tener que rediseñar nuevamente el panel de administración.

Nueva sección

Variantes del producto

TIENDA (VISTA DEL CLIENTE)

Si un producto no tiene tallas activadas...

Debe comportarse exactamente igual que ahora.

No mostrar ninguna opción adicional.

Si el producto tiene tallas...

Mostrar debajo del precio una sección:

Selecciona una talla

Las tallas deben verse como botones horizontales modernos.

Ejemplo:

[S] [M] [L] [XL] [2XL]

No utilizar listas verticales.

No utilizar un selector desplegable.

Debe verse limpio, premium y moderno, similar a tiendas como Nike, Adidas o Zara.

Tallas disponibles

Las tallas disponibles deben verse normalmente.

Las tallas no disponibles deben seguir apareciendo pero:

color gris
menor opacidad
no deben poder seleccionarse

De esta forma el cliente entiende qué tallas existen y cuáles están agotadas.

No ocultarlas completamente.

Selección obligatoria

Si el producto utiliza tallas...

Debe ser obligatorio seleccionar una antes de poder comprar.

Esto aplica para:

Comprar por WhatsApp
Comprar contra entrega
Agregar al carrito

Si el usuario intenta continuar sin elegir una talla...

No permitir continuar.

Mostrar un mensaje amigable como:

"Por favor selecciona una talla antes de continuar."

No utilizar alertas del navegador.

Utilizar el mismo estilo visual del resto del sitio.

Carrito

Cuando un producto tenga talla...

La talla seleccionada debe mostrarse debajo del nombre del producto.

Ejemplo:

Camiseta Hugo Boss

Talla: XL

Pedido

La talla elegida debe guardarse junto con el pedido.

Debe enviarse:

al correo
al panel administrativo
al pedido almacenado

Ejemplo:

Producto:

Camiseta Hugo Boss

Talla:

XL

Edición de productos

Si posteriormente el administrador modifica las tallas disponibles...

Los cambios deben reflejarse automáticamente en la tienda.

Ejemplo:

Antes:

☑ M

☑ L

☑ XL

Después:

☑ S

☑ M

☑ L

En la tienda:

XL debe aparecer en gris y ya no debe poder seleccionarse.
